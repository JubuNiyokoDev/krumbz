# Ikirenge (boutique de démonstration chaussures) — photos à fournir

Déposer chaque fichier avec **exactement** ce nom dans `public/images/tenants/ikirenge/`.
Tant qu'un fichier manque, le site affiche un visuel provisoire ; il est remplacé automatiquement dès le dépôt.

**Règles communes (comme Krumbz)**
- Style : photo réaliste, lumière chaude naturelle, Burundi (Bujumbura, lac Tanganyika, collines), personnes souriantes et naturelles.
- **Une chaussure Ikirenge bien visible** dans chaque scène (portée ou tenue), sans autre marque ni logo visible.
- **Paysage (16:9)** : personnes et chaussure sur **un seul côté** (gauche OU droite) ; l'autre côté reste calme (mur, ciel, lac, verdure) — le texte et la chaussure 3D s'y placent.
- **Portrait (9:16)** : personnes et chaussure dans les **deux tiers du haut** ; le **tiers du bas** reste calme (sol, sable, mur).
- JPG, qualité élevée ; le site compresse automatiquement.
